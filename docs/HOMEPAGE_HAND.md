## Модель и управление

Один `fetch` с браузерным кэшированием загружает GLB. `GLTFLoader` использует локальный `MeshoptDecoder` из установленного Three.js. URL создаёт существующая функция `href`, включая базовый путь Astro.

Исходный клип `INOE_Hand_10s`: 10 секунд, 69 каналов, 21 кость, шесть деформируемых сеток. Геометрия, веса, ногти и материалы не меняются. Вся модель один раз повёрнута на 180° вокруг Z: предплечье находится ниже кулака, тыльная сторона обращена к зрителю. Затем родительская группа наклоняет руку вперёд только вокруг X, от 0 до 90°, с постоянным плечом 0,197 м. К 58% входного движения наклон завершён: полураскрытая и полностью открытая ладонь обращены вверх. Бокового вращения и отражения нет; большой палец остаётся с одной стороны. Перспективная камера с углом 34° приподнята над сценой, чтобы горизонтальная ладонь оставалась видна. Дополнительной геометрии локтя нет. Запечённый прямой спуск компенсируется на уровне контейнера по положению запястья; исходное раскрытие пальцев, морфы и движения запястья остаются из GLB. Камера адаптирует расстояние к соотношению сторон экрана.

`AnimationMixer` вычисляет одно приостановленное действие: задаётся `action.time`, затем вызывается `mixer.update(0)`. Достижение последнего кадра не отключает обратное перемещение.

Время руки задаёт прокрутка. При 0% экран чёрный. На 0–64% закреплённого пути кулак приближается из глубины, опускается по пространственной дуге и разворачивает ладонь; готовый клип проходит от 0 до 10 секунд. Название начинает проявляться после 6,5 секунды клипа, когда пальцы уже раскрыты. Монотонная кубическая интерполяция распределяет фазы с непрерывной скоростью. На 64–66,5% открытая поза коротко задерживается. На 66,5–100% движение обращается: рука уходит по дуге в глубину и исчезает, тот же логотип перемещается в шапку. Закрепление снимается на 97%, когда рука почти исчезла. Обратный скролл возвращает те же позы.

Рука и её свечение имеют отдельную прозрачность: до 26% пути они полностью невидимы, на 26–38% плавно проявляются, на 71–81% гаснут и дальше остаются скрытыми. Частицы, ленты и перемещение названия сохраняют собственное управление. При нулевой прозрачности поверхность руки вместе с ореолом исключается из отрисовки.

Закреплённый путь — 570svh на широком экране и 500svh на узком; пауза с раскрытой рукой занимает лишь 2,5% пути. Для проявления и переноса названия используются кривые пятой степени. Между событиями колеса прогресс догоняет целевую позицию с постоянной времени 190 мс; после достижения цели цикл управления скроллом останавливается. При большом переходе к началу/концу, при resize и уменьшенном движении применяется точная позиция. Автовоспроизведения руки нет. Дополнительные кадры даёт интерполяция существующего клипа в браузере, без увеличения GLB.

Фоновая пыль движется и при неподвижном скролле: 190 частиц на широком экране, до 100 на узком. Сохранён одобренный световой концепт: серебристые ленты сходятся к ладони, складки медленно переливаются, часть пыли течёт вдоль этих же кривых. Координаты ладони и кончиков пальцев проецируются через фактическую камеру. Надпись располагается над ладонью с зазором до пальцев; к ней поднимаются редкие частицы и мягкий свет. Свечение и потоки усиливаются при раскрытии, затем гаснут при уходе руки. Сохраняется мягкое сияние её реального силуэта и тонкая светлая кромка. Геометрия GLB не меняется.

## HTML-название

На всём пути используется один `data-hub-logo`. Невидимый метрический текст задаёт размеры; целевые размеры берутся из существующего места логотипа в шапке. В основной сцене положение названия связано с проекцией ладони, верхнего кончика пальца и края предплечья: слово остаётся над всей рукой и ограничено полями экрана. При смене позы обновляются якоря, после загрузки шрифта и при resize — размеры. Лёгкое плавание слова создаёт CSS-анимация, не меняющая его разметку. Название расположено вне sticky-слоя руки, поэтому остаётся поверх шапки после выхода hero из экрана.

Общий `BrandWordmark.astro` рисует слово «ИНОЕ» из четырёх редактируемых SVG-контуров по мотивам референса. Перламутровая поверхность, теневая грань и светлая кромка создают скульптурный эффект. В hero есть шесть неглубоких CSS-слоёв на букву. Буквы мягко выходят из расфокуса, приподнимаются с небольшим наклоном; узкий серебристый блик проходит внутри контура каждой буквы. С появлением огонька светлеют грани букв, подсвечивается контур и видны небольшие блики на верхних кромках. Наклон, глубина и свечение сходят к нулю при переходе в шапку. Эффект ограничен hero и не меняет статические логотипы других страниц.

## Производительность и доступность

Three.js загружается динамически только для главной. DPR ограничен 1,5 на широких экранах и 1,25 на узких. Рука рассчитывается при смене позы и resize; неподвижная поза сохраняется в render target. Для сияния силуэт размывается в два прохода в буферах с четвертью ширины и высоты, только при смене позы. Пока видна сцена, лёгкая композиция с пылью и лентами обновляется не чаще 30 раз в секунду. В чёрном старте, после завершения, вне экрана и в скрытой вкладке цикл останавливается. При уходе со страницы освобождаются модель, фон, все render target, материалы и обработчики; BFCache сохраняет рабочую сцену. Новых растровых текстур и npm-зависимостей для эффектов нет.

Canvas пропускает клики и скролл и исключён из доступного дерева. `prefers-reduced-motion` и сохранённый спокойный режим сразу показывают текст и ссылки, не загружая GLB и WebGL. Ошибки HTTP, WebGL, потеря контекста и таймаут оставляют работающую навигацию.

## Проверки

Проверки: `npm run check`, `npm run build`, `npm test`; 35 маршрутов и 158 тестов. Проверяются одинаковое сглаживание на 30, 60 и 120 Гц, непрерывность скорости, обратимость, задержка проявления букв до раскрытия ладони, неизменная длина рычага, приближение в перспективе, ограничение числа частиц и освобождение ресурсов фона. Для сияния проверяются размеры дополнительных буферов, восстановление исходного render target и очистка поверхности.

В браузере проверены широкая компоновка и мобильный viewport 391×844 CSS px, реальный GLB, окончание вступления, промежуточная поза, оба направления скролла и docking. На мобильном экране горизонтального переполнения нет. Расхождение границ названия и места в шапке при docking меньше 0,02 CSS px.

Отказ GLB проверен локальным сервером с HTTP 503 только для модели: текст виден, canvas удалён, ссылки `/iznanka/`, `/arhiv/`, `/ostrov/` сохранены. Тест Three.js дополнительно декодирует фактический файл и проверяет возвращение костей и морфов из конца клипа в предыдущие позы. Исходники миров и Blender-проекты не изменены.

Обновлённая проверка GLB вычисляет направление ладони по настоящим костям, проверяет горизонтальную полураскрытую позу и постоянную сторону большого пальца. Снимки постановки с ладонью вверх: `docs/review-after/inoe-palm-up/`. На физических телефонах скорость не измерялась; мобильная компоновка проверяется в браузере.

## Просмотр

```bash
npm run dev -- --host 127.0.0.1
```

Открыть адрес из вывода Astro, обычно `http://127.0.0.1:4321/`, и прокрутить вниз. Старт остаётся чёрным до прокрутки. Прокрутка вверх возвращает композицию.
