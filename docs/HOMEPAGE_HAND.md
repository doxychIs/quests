Интеграция для существующего сайта `https://doxychis.github.io/quests/`, 8 ноября 2026.

## Модель и управление

Один `fetch` с браузерным кэшированием загружает GLB. `GLTFLoader` использует локальный `MeshoptDecoder` из установленного Three.js. URL создаёт существующая функция `href`, включая базовый путь Astro.

Исходный клип `INOE_Hand_10s`: 10 секунд, 69 каналов, 21 кость, шесть деформируемых сеток. Геометрия, веса, ногти и материалы не меняются. По последнему указанию пользователя вся импортированная сцена повёрнута на 180° вокруг вертикальной оси: ладонь смотрит к зрителю. Это поворот, не зеркальное отражение. Свет и фронтальная ортографическая камера настраиваются отдельно.

`AnimationMixer` вычисляет одно приостановленное действие: задаётся `action.time`, затем вызывается `mixer.update(0)`. Достижение последнего кадра не отключает обратное перемещение.

Единственный источник времени — прокрутка. При 0% экран чёрный. На 0–64% закреплённого пути готовый клип проходит от 0 до 10 секунд: кулак опускается, пальцы раскрываются, появляются буквы. На 64–66,5% открытая поза коротко задерживается. На 66,5–100% клип проигрывается назад: рука медленно поднимается и постепенно исчезает, тот же логотип перемещается в шапку. Закрепление снимается на 97%, когда рука почти исчезла. Обратный скролл возвращает те же позы.

Закреплённый путь увеличен до 570svh на широком экране и 500svh на узком. По сравнению с предыдущей версией вход длиннее на четверть, а обратный ход — примерно на 40%; пауза с раскрытой рукой занимает лишь около 2,5% пути. Кривые пятой степени имеют нулевую скорость и ускорение на границах. Между событиями колеса прогресс догоняет целевую позицию с постоянной времени 190 мс, смягчая быстрые прокрутки; после достижения цели RAF останавливается. При большом переходе к началу/концу, при resize и уменьшенном движении применяется точная позиция. Автовоспроизведения нет. Дополнительные кадры даёт непрерывная интерполяция существующего клипа в браузере, без увеличения GLB.

## HTML-название

На всём пути используется один `data-hub-logo`. Невидимый метрический текст сохраняет исходное место; целевые размеры берутся из существующего места логотипа в шапке. Координаты пересчитываются после загрузки шрифта и при resize. Название расположено вне sticky-слоя руки, поэтому остаётся поверх шапки после выхода hero из экрана.

Общий `BrandWordmark.astro` рисует только слово «ИНОЕ» из четырёх редактируемых SVG-контуров по мотивам референса. Перламутровая поверхность, теневая грань и светлая кромка создают скульптурный эффект. В hero есть шесть неглубоких CSS-слоёв на букву; наклон и глубина сходят к нулю при переходе в шапку. Отдельного символа «И», WebGL-текста и бесконечной декоративной анимации нет.

## Производительность и доступность

Three.js загружается динамически только для главной. DPR ограничен 1,5 на широких экранах и 1,25 на узких. Новые кадры рисуются при скролле и его коротком сглаживании, resize и изменении видимости. Вне экрана и в скрытой вкладке рендер останавливается. При уходе со страницы GPU-ресурсы освобождаются; BFCache сохраняет рабочую сцену.

Canvas пропускает клики и скролл и исключён из доступного дерева. `prefers-reduced-motion` и сохранённый спокойный режим сразу показывают текст и ссылки, не загружая GLB и WebGL. Ошибки HTTP, WebGL, потеря контекста и таймаут оставляют работающую навигацию.

## Проверки

Проверки: `npm run check`, `npm run build`, `npm test`; 35 маршрутов и 155 тестов. Отдельный тест проверяет одинаковое сглаживание на 30, 60 и 120 Гц, отсутствие перелёта и обратное движение.

В браузере проверены широкая компоновка и мобильный viewport 391×844 CSS px, реальный GLB, окончание вступления, промежуточная поза, оба направления скролла и docking. На мобильном экране горизонтального переполнения нет. Расхождение границ названия и места в шапке при docking меньше 0,02 CSS px.

Отказ GLB проверен локальным сервером с HTTP 503 только для модели: текст виден, canvas удалён, ссылки `/iznanka/`, `/arhiv/`, `/ostrov/` сохранены. Тест Three.js дополнительно декодирует фактический файл и проверяет возвращение костей и морфов из конца клипа в предыдущие позы. Исходники миров и Blender-проекты не изменены.

Предыдущие снимки: `docs/review-after/hub-hand/`; актуальное фирменное оформление: `docs/review-after/inoe-brand/`. На физических телефонах скорость не измерялась; мобильная компоновка проверяется в браузере.

## Просмотр

```bash
npm run dev -- --host 127.0.0.1
```

Открыть адрес из вывода Astro, обычно `http://127.0.0.1:4321/`, и прокрутить вниз. Старт остаётся чёрным до прокрутки. Прокрутка вверх возвращает композицию.
