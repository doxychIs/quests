# Hero и выбор миров — 7 ноября 2026

Изменены только первый экран, поведение шапки и выбор миров. Остальные блоки главной и сами миры сохранены.

- В hero только «ИНОЕ». Четыре буквы разделены на три графические полосы для обратимой анимации наведения, без циклического глитча. В покое показывается цельный текст без швов.
- Один и тот же логотип привязан к прокрутке: из центра hero он уменьшается до места логотипа в липкой шапке; при обратной прокрутке возвращается. На первом экране отдельного логотипа в шапке нет.
- Геометрия измеряется заново при изменении размеров и загрузке шрифтов. Анимационного таймера в покое нет; скрытая вкладка не обновляет положение.
- У выбора миров убраны заголовок, подписи и описания. Чёрная панель с названием уходит влево, справа появляется оформление мира.
- «Изнанка»: реальный кадр обычного коридора 3D-страницы до поднятия камеры, без крови, призраков или резких сцен. «Архив»: те же бумага, библиотечная фотография и Marck. «Остров»: фон первого экрана и Comfortaa. Новые генерации изображений не использовались.
- Ссылки остаются обычными ссылками, фокус открывает те же превью. На touch-устройствах превью видны сразу, открытие мира — одним нажатием.
- При уменьшенном движении нет расщепления или сдвига панелей; логотип переключается между неподвижными положениями.

Проверка: TypeScript, статическая сборка и 148 тестов. В браузере проверены центрирование, расщепление, переход в шапку, раскрытие всех трёх миров, светлая тема и ширина 390 px. На узком экране нет горизонтального скролла. Фон коридора получен из собственного снимка сайта `docs/review-after/november-release/room-live.png`.
`nГотовая сборка с префиксом `/quests/` проверена отдельно: шапка остаётся при y=0, уменьшенный логотип попадает в её левую область, нажатие возвращает в hero. Для шапки повышен приоритет селектора, чтобы общий CSS не заменял sticky на relative при объединении стилей Astro.
