# Публикация ИНОЕ

Исходники: https://github.com/doxychIs/quests

Сайт: https://doxychis.github.io/quests/

Портфолио: https://doxychis.github.io/#projects

Готовый сайт находится в папке `quests/` репозитория `doxychIs/doxychIs.github.io` и публикуется действующей системой GitHub Pages портфолио. Это тот же способ размещения, который используется для остальных работ автора. Главная страница портфолио и остальные проекты остаются в своих папках.

В репозитории `quests` GitHub Actions проверяет TypeScript, собирает сайт, запускает тесты и сохраняет готовую версию с префиксом `/quests/` как артефакт `quests-site`. Отдельный GitHub Pages для этого репозитория не требуется. Не включайте его одновременно с версией в портфолио: оба варианта используют один адрес `/quests/`.

Для обновления из исходников:

```powershell
npm ci
npm run check
npm run build
npm test
$env:SITE_URL = 'https://doxychis.github.io'
$env:BASE_PATH = '/quests/'
npm run build
```

Скопируйте содержимое `dist/` в `quests/` репозитория портфолио, сохраняя все подпапки, и отправьте изменение в `main`. Не копируйте `node_modules`, `.astro`, локальные настройки и ключи. Все материалы из `public/` должны присутствовать: неполная загрузка может собрать HTML, но оставить сайт без изображений, шрифтов и видео.

Для первого экрана АРХИВА и ОСТРОВА будущие фоновые видео настраиваются отдельно в `src/lib/world-media.ts`. Пролёты управляются прокруткой и не используются фоном первого экрана.
