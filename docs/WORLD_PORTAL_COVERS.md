# Обложки трёх миров на главной

Созданы встроенным инструментом imagegen. Это новые статичные изображения для ссылок выбора мира; видеосцены самих миров не менялись.

Файлы для сайта: `public/assets/portal-iznanka-v1.webp`, `public/assets/portal-arhiv-v1.webp`, `public/assets/portal-ostrov-v1.webp` (768 × 1152). Для каждого есть вариант с суффиксом `-small` (384 × 576). Изображения перекодированы в WebP с качеством 84; браузер выбирает разрешение через `srcset`.

Оригиналы PNG сохранены локально в `.publish/world-cover-sources/`.

В общей обложке «Изнанки» показано только пустое помещение и телевизор с рябью. Вход в сам мир по-прежнему требует согласия 18+.
